Installation

imgshrink resizes and compresses images from the terminal. It runs on macOS, Linux and Windows with Python 3.9 or newer.

Install with pip

pip install imgshrink

Check that it works with imgshrink --version.

⚠️
Warning: imgshrink overwrites files in place unless you pass --out. Keep a backup the first time you run it on a folder.

Basic usage

imgshrink photos/ --width 1600 --quality 82 --out resized/

Common options

OptionDefaultDescription
--widthnoneResize to this width, keeping the aspect ratio.
--quality85JPEG and WebP quality from 1 to 100.
--formatsameConvert to jpg, png, webp or avif.
--outin placeWrite results to this folder.
