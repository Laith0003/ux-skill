## Filed from this run

- Render timing is wall-clock: state-answers-late fires on a control near its threshold in one run and not the next. The determinism section lists the pages where it happened in this run; the finding keys ignore the measured value, so only an appearing or vanishing finding counts.
- Static excerpts show the first 200 characters of the line, not the match. On minified CSS and one-line HTML the excerpt never shows what fired (most of the excerpt-view cantTell labels, and most negative alphas, come from this). Phase 2's selector field fixes it.
- The stored pages carry no scripts and the render pass blocks the network, so no image or web font from another host loads; image-broken fires on every remote image and icon links can collapse. Phase 2's network blocking has to choose what counts as a finding then.
- placeholder-token-shipped matches lorem ipsum, so every lorem-ipsum-leak finding is counted twice.
- imagery-mandatory-missing fires on pages that are not landing pages (sign-in, settings, dashboards, blog, a plain content page) and on the seeded base page.
- Seeded misses: img with width but no height, a textarea named only by its placeholder, transition shorthand with no property (transition: 0.2s, which means all), and an SVG image stretched out of shape.
