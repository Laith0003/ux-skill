# Proposed checks, ranked

Every check the four raw reports propose, merged and ranked by impact on whether a page works first and how un-generic it looks second. Before a row was marked new, data/anti-patterns.json, the render rule tables (engine/render/core.py, taste.py, interact.py), the linter rule ids in engine/linter/, PLAN-4.1-inventory.md and research/library/checks.md were searched. "Existing rule" names an engine rule id; a library or inventory proposal is named in brackets after "none". Pass: static (lint of source or artifact), render (measured in a browser), interact (the page is driven). Thresholds are proposals for Phase 5 to measure on the benchmark, not settled values.

Counts: 85 rows. new 66, tune existing 8, drop as duplicate 11.
