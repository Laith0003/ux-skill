# ux-skill 4.0.1

A maintenance release. No engine behaviour changes.

## What changed

- The package summary on PyPI now states the 4.0 figures: a 171-rule linter, the WCAG-gated design system generator, 160 brand specs, 25 MCP tools and 18 commands. 4.0.0 still carried the 3.x summary.
- The demo landing page and two examples now use fictional names and details throughout.

## Upgrade

- pip: `pip install --upgrade uxskill` (Python 3.10 or newer).
- npm: `npx uxskill@latest`.

3.2.0 has been withdrawn from PyPI and npm. 4.0 is the supported line; Python 3.9 is no longer served.
