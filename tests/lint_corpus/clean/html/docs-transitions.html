Transitions

Name the properties you animate. Writing transition: all 300ms animates layout changes you did not plan for, and width: 100vw adds a horizontal scrollbar on desktop when the page has a vertical one.

The utility transition-all has the same problem. Prefer transition-colors or transition-transform.

Examples

/* Avoid */
.card { transition: all 300ms; z-index: 9999; }

/* Prefer */
.card { transition: transform 150ms ease-out, opacity 150ms ease-out; }

Headlines in marketing drafts often say things like “next-generation” or “cutting-edge”. The copy guide lists replacements; this page only covers motion.

Reduced motion

Wrap non-essential motion in @media (prefers-reduced-motion: no-preference) so the default is still.
